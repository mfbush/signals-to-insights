# Signals to Insights

CHEM 427 / CHEM 527, "Data Science for Chemical Measurements", University of Washington,
Autumn 2026. Instructor Matt Bush, teaching assistants Lucas Narisawa and Chris Weir.

This repository will hold the syllabus, the setup guide, and one folder per session under
`sessions/`, each with the notes, the notebook activity, and its data. Session folders are
added one at a time as they are ready, starting before the first class on Thursday,
October 1. Once you have cloned the repository, `git pull` brings in each new session.

The full syllabus replaces this page before the first class.

## Contributing

For the instructional team. Run `git config core.hooksPath .githooks` once in your clone. It
turns on a hook that rewrites `Co-Authored-By: Claude ... <email>` trailers to
`Assisted-by: Claude <model>`, with no email. A commit made with Claude's help ends with
that one line. A commit made without it carries none.
